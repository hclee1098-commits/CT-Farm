# 개발 플랫폼 시작

> **알 수 있는 것:** 설정·동작·제한과 실제 사용 절차
>
> **읽을 때:** 해당 기능의 상세 설정을 확인할 때
>
> **관련 기능:** 개발 플랫폼 시작
>
> **관련 소스:** [server.mjs](../../tools/dev-portal/server.mjs)
>
> **관련 문서:** [문서센터](../README.md)


이 버전은 `SECURE-LIFECYCLE.ps1 -Action SETUP|STARTER|STOP`으로 관리합니다. EXE 생성은 필요하지 않습니다. 최신 환경별 실행은 [LOCAL부터 운영 모니터링까지 안내](../05-운영과보안/환경분리-배포-모니터링-실행안내.md)를 따르세요.

## 설치

Node.js 22 이상에서 프로젝트 루트의 `npm ci --ignore-scripts`, `npm run db:generate`를 실행하세요. 기존 DB를 사용하는 경우 환경설정과 백업을 확인한 뒤 기존 migration deploy 절차를 사용하세요. reset 및 Docker volume 삭제는 사용하지 않습니다.

## 별도 로컬 포털 (PowerShell 5.1)

```powershell
$bytes = New-Object byte[] 32
$rng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
try { $rng.GetBytes($bytes) } finally { $rng.Dispose() }
$env:DEV_PORTAL_TOKEN = [Convert]::ToBase64String($bytes)
# 이 값을 로컬 포털 입력란에 붙여넣으세요. 공유하거나 로그에 저장하지 마세요.
$env:DEV_PORTAL_TOKEN
npm run dev:portal
```

`http://127.0.0.1:4310`에 접속합니다. localhost 별칭은 Host 검증에서 거부됩니다. 서버는 127.0.0.1에만 바인딩하고 설정 누락/production에서 실행을 거부합니다. 접근키는 서버 시작 후 1시간 만료됩니다. 종료는 Ctrl+C입니다. 접근키는 일반 사용자 JWT와 별개이며 브라우저 영구 저장소에 저장하지 않습니다. 로컬 접근키는 MFA 관리자 인증의 대체 수단이 아닙니다. 이 도구를 원격 공개하지 마세요.

## 관측 수집

`SECURE-LIFECYCLE.ps1 -Action STARTER`가 API·WEB와 독립 LOCAL 수집기를 실행합니다. 포털은 `.starter-state/monitoring/LOCAL/`의 안전한 이벤트와 실제 HTTP 상태를 표시합니다. STAGING/PRODUCTION은 TLS 중앙 수집 서버와 환경별 읽기 키를 설정해야 합니다. 운영 모니터링과 실시간 로그 화면에서 환경·서비스·수준·시간·검색 필터를 사용합니다.

기존 `dev:api:observed`, `dev:web:observed`는 이전 표본 수집과의 호환용입니다. 새 통합 화면은 이전 developer-events.jsonl 대신 새 이벤트 저장소를 조회합니다. 데이터 없는 원격 환경에 가짜 상태나 배포 이력을 표시하지 않습니다. 전체 절차와 제한은 [통합 실행 안내](../05-운영과보안/환경분리-배포-모니터링-실행안내.md)를 확인하세요.

`npm run analyze`, `npm run docs:index`, `npm run docs:check`, `npm run test:portal`로 갱신/검증합니다. 포털 데이터는 시작 시 스냅샷이므로 소스 변경 후 서버를 다시 시작하세요.
