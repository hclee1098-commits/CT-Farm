# 전체 기능과 구현 근거

> **알 수 있는 것:** 기능의 목적·구현 범위·화면·API·소스·테스트 근거
>
> **읽을 때:** 어떤 기능을 재사용할지 판단할 때
>
> **관련 기능:** SECURE STARTER V6 전체 모듈
>
> **관련 소스:** [API 진입점](../../apps/api/src/bootstrap/app.ts), [웹 화면](../../apps/web/src/app/starter)
>
> **관련 문서:** [문서센터](../README.md), [현재 검증](../07-기술참고/문서정리-검증결과.md)

**구현 완료**는 기재한 범위의 코드가 존재하고 처리 흐름을 확인한 판정입니다. 이번 환경에서 모든 기능의 실행 성공 또는 운영 승인을 뜻하지 않습니다. **부분 구현**은 알려진 기능 제한, **미구현**은 기능 본체 부재, **확인 필요**는 환경 의존 동작을 확인하지 못한 경우입니다. 테스트 열은 존재 근거이며 실행 결과는 현재 검증에서 따로 확인하세요.

포털 상단에서 기능명·API·소스 경로로 내용 검색할 수 있습니다.
