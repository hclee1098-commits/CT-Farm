# 설치·서버·데이터베이스 오류 해결

> **알 수 있는 것:** 오류별 확인 명령과 안전한 재시도
>
> **읽을 때:** 설치나 실행이 멈췄을 때
>
> **관련 기능:** 설치·서버·데이터베이스 오류 해결
>
> **관련 소스:** [SECURE-LIFECYCLE.ps1](../../SECURE-LIFECYCLE.ps1) · [health.ts](../../apps/api/src/bootstrap/health.ts)
>
> **관련 문서:** [문서센터](../README.md)

| 증상 | 확인 방법 | 다음 행동 |
|---|---|---|
| Docker 연결 실패 | `docker info` | Docker Desktop을 켜고 엔진 준비 후 SETUP 재시도 |
| 환경파일 없음 | SETUP 완료 여부 | 새 설치는 SETUP 실행, 기존 설치는 원래 환경파일 복원 |
| DB 연결 실패 | `docker compose ps` | 현재 폴더의 프로젝트인지 확인하고 DB/Redis 로그 확인 |
| 포트 충돌 | STARTER 출력과 설치 상태 | 다른 프로세스를 무작정 종료하지 말고 소유권·포트 확인 |
| API 실행 실패 | `/health/live`, `/health/ready` | live는 프로세스, ready는 DB/Redis 준비 상태를 구분 |
| 문서센터 401 | 키 길이와 시작 시각 | 32자 이상 키로 포털 재실행, 1시간 만료 후 재접속 |
| 문서센터 403 | 주소와 Origin | `http://127.0.0.1:4310` 사용, 외부 프록시로 공개 금지 |
| 문서를 수정했는데 그대로 | 포털 시작 시점 | 문서 저장 후 포털을 종료하고 다시 실행 |

```powershell
docker compose ps
docker compose logs --tail 100 postgres redis
```

로그를 공유하기 전 비밀번호·토큰을 가리세요. `down -v`, 전역 prune, DB reset은 복구 절차에 포함하지 않습니다.
