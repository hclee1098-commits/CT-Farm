## 백업과 안전한 복원

`backup/문서정리-이전문서.zip`에 이동·삭제 전 문서를 보관했습니다. 원본 첨부 ZIP도 변경하지 않았습니다. 전체 변경을 되돌리려면 **새 빈 폴더**에 원본 첨부를 풀어 비교하세요. 문서 백업만 복원할 때도 별도 폴더에 먼저 풀고 필요한 문서만 선택합니다. 실제 운영 폴더의 환경파일·DB·업로드를 통째로 덮어쓰지 않습니다.

기존 소스·마이그레이션·PowerShell은 바이트 비교로 확인하며 결과는 [검증결과](문서정리-검증결과.md)에 기록합니다. 링크를 가진 코드 참조도 새 경로로 갱신합니다. 이력 로그 내부 문자열은 당시 기록으로 남깁니다.
