# 전체 기능 사용 방법과 구현 근거

기준일: 2026-10-30. 구현 파일의 존재와 운영 검증을 구분합니다. 최신 웹·별도 앱 범위는 [모바일 앱과 디자인](모바일앱과-디자인.md), 음성·협업·장애 검증은 [6차 결과](6차-음성과-실행복구.md)를 함께 읽으세요.

## 먼저 알아두세요

각 항목의 검증 상태는 명시한 시험 범위에 한정됩니다. 현재 실행 결과는 [문서 관리](문서-관리.md)에 별도로 기록합니다. 기존 농장 쓰기는 로그인한 소유자 범위이며 읽기 공유는 별도 workspace 경로에서만 제공하고, API는 화면을 숨기는 것과 별도로 서버에서 권한을 검사합니다. 공통 오류: 400 입력, 401 인증, 404 권한 범위의 자료 없음, 409 버전·중복·상태 충돌입니다.

## 농장 등록·수정·보관

- 목적: 농장 위치·주소·면적을 관리합니다.
- 사용법·화면 위치: 내 농장 → 농장 등록 또는 상세 수정. 삭제는 보관이며 복원할 수 있습니다.
- 프론트엔드: [apps/web/src/app/starter/farms/page.tsx](../../apps/web/src/app/starter/farms/page.tsx)
- 백엔드: [apps/api/src/modules/farms/farms.controller.ts](../../apps/api/src/modules/farms/farms.controller.ts)
- API: `/api/v1/farms` (개별 하위 경로는 API 목록 참조)
- 데이터베이스: Farm
- 의존성: 기존 인증·입력 검증·PostgreSQL, 농장 기능은 농장 소유권 검사. 외부 공급자 설정은 외부 연동 안내 참조.
- 보안·접근 권한: 사용자 세션과 서버 권한 검사. 장치 수집은 별도 장치 키만 사용. 비밀키를 브라우저에 저장하지 않음.
- 현재 구현 상태: **구현 및 검증 완료**
- 테스트·알려진 문제·개선: 좌표·면적 입력, 버전 충돌·소유권·보관·복원 검사. 법적 토지 소유권을 확인하는 기능은 없습니다.
- 검증 근거: API·웹 단위 테스트 및 tools/test-farm.mts 계열 통합 시험. 이번 실행 결과와 이전 보고는 문서 관리에서 구분.
