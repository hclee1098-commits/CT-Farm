## 기존 공통 시스템 상세 참고

**이번 환경분리·모니터링 버전:** [초보자용 LOCAL → STAGING → PRODUCTION 실행 안내](05-운영과보안/환경분리-배포-모니터링-실행안내.md). 실제 원격 배포와 Windows/Docker 실기는 별도 확인이 필요합니다.


설치 → 기능 확인 → 개발 → 운영 순서로 필요한 안내를 찾으세요. 처음에는 **설치와 실행**, **전체 기능**, **전체 구조** 세 문서만 읽으면 됩니다.

> **알 수 있는 것:** 모든 안내·명세·검증 기록의 위치
>
> **읽을 때:** 처음 시작하거나 필요한 문서를 찾을 때
>
> **관련 기능:** 통합 문서 탐색과 검색
>
> **관련 소스:** [로컬 문서센터](../tools/dev-portal/server.mjs)
>
> **관련 문서:** [루트 시작 안내](../README.md)

코드가 있다는 사실과 운영 검증 완료는 다릅니다. [이번 검증 결과](07-기술참고/문서정리-검증결과.md)에서 실제 실행 범위를 확인하세요.
